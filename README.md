# FaBuYe

#残月个人发布页

一个简洁的个人引导页，支持必应每日壁纸背景、拟态风格设计、背景音乐播放

✨ 功能特点

· 拟态风格设计：卡片、按钮采用 Neumorphism 拟态阴影效果
· 必应每日壁纸：背景自动调用必应每日一图 API
· 多线路入口：支持国际线路和中国线路的站点切换
· 响应式布局：适配手机端和电脑端浏览
· 收藏引导：提供 iOS/Android 添加书签的操作提示
· 背景音乐：页面加载自动播放音乐
· 防失联机制：顶部固定显示联系邮箱，域名变动时可通过邮箱获取最新地址

📁 项目结构

```
canyue-page/
├── index.html          # 主页面
├── css/
│   └── zui.min.css     # ZUI 框架样式
├── js/
│   ├── jquery.js       # jQuery 库
│   └── zui.min.js      # ZUI 框架脚本
├── img/
│   └── logo.png        # 网站 Logo
└── favicon.ico         # 网站图标
```

🚀 快速开始

1. 克隆或下载本项目到本地
2. 将项目部署到任意静态服务器
3. 确保 css/ js/ img/ 目录中的依赖文件路径正确
4. 访问网站域名即可

🛠️ 技术栈

· HTML
· Bing 每日壁纸 API - 背景图片
· 网易云音乐外链 - 背景音乐

📝 自定义修改

· 修改站点链接：编辑 index.html 中 <a class="col-sm-6 card"> 标签的 href 属性
· 修改背景音乐：替换 <audio> 标签中 src 的网易云音乐 ID（id=2163973290）
· 修改 Logo：替换 img/logo.png 文件
· 修改联系方式：搜索 1771245847@qq.com 替换为你的邮箱
· 调整拟态效果：修改 CSS 中 .card、.field 的 box-shadow 和 background 值
